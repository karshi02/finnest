# รายงาน #21: คำนวณอัตโนมัติ รอบ 1 + 2

วันที่: 2026-10-15
Deploy: https://fitt-zeta.vercel.app (cache `fittrack-v10`)
ทำตาม: [PLAN-AUTO-CALC.md](PLAN-AUTO-CALC.md) ข้อ A1, A2, A9, B0–B3 ใช้ค่าที่แนะนำทุกข้อ

## สิ่งที่ทำ

### รอบ 1: ไม่ต้องกรอกอะไรเพิ่ม

| ID | ฟีเจอร์ | ตรงไหน |
|---|---|---|
| A1 | กรอก HR เฉลี่ยแล้ว**ระดับความเข้มเลือกให้เอง** จากโซน Karvonen (ต้องมีอายุ + HR พักในโปรไฟล์) และกด "บันทึกเป็นคาร์ดิโอ" จาก stopwatch ก็เลือกให้ด้วย | ฟอร์มคาร์ดิโอ |
| A2 | **Pace / ความเร็ว** แสดงสดระหว่างกรอก (วิ่ง/เดิน = นาที/กม., ปั่น = กม./ชม.) และมี**คอลัมน์ Pace** ในประวัติ | ฟอร์ม + ประวัติคาร์ดิโอ |
| A9 | **นาฬิกาพักเริ่มเอง**หลังกด "บันทึก Set" มีสวิตช์ปิดได้ (ค่าเริ่มต้น: เปิด) | การ์ดนาฬิกาพัก |

### รอบ 2: โปรไฟล์ครั้งเดียว

| ID | ฟีเจอร์ | รายละเอียด |
|---|---|---|
| B0 | **โปรไฟล์ของฉัน** | เพศ อายุ น้ำหนัก ส่วนสูง HR พัก อยู่บนสุดของหน้าคำนวณ เปิดได้จากปุ่ม **👤** บนแถบด้านบน ตรวจค่าทีละช่อง (เดิมถ้าค่าใดค่าหนึ่งผิด จะทิ้งทั้งโปรไฟล์) |
| B1 | **แคลอรี่คาร์ดิโออัตโนมัติ** | เว้นช่องแคลอรี่ว่าง = คำนวณให้ มี HR ≥ 90 + เพศ + อายุ ใช้สูตร Keytel และคณะ (2005) ไม่งั้นใช้ MET × น้ำหนัก × เวลา ช่องแคลอรี่แสดงค่าประมาณให้เห็นก่อนบันทึก ใช้กับกิจกรรมจาก Strava ที่ไม่มีแคลอรี่ และหน้าต่าง "บันทึกออกกำลังกาย" ด้วย |
| B2 | **แคลอรี่เวทเทรนนิ่ง** | MET 3.5 (หรือ 6 ถ้า RIR เฉลี่ย ≤ 1) × น้ำหนักตัว × เวลาจาก set แรกถึง set สุดท้าย + 2 นาที **การ์ด "🔥 แคลอรี่เผา" ในหน้าภาพรวมนับเวทด้วยแล้ว** (เดิมเป็น 0 เสมอ) |
| | คำนวณย้อนหลัง | ครั้งแรกที่ใส่น้ำหนัก แอปจะถามว่าจะคำนวณแคลอรี่ให้รายการเก่าที่เป็น 0 ไหม |
| B3 | **เติมเครื่องคำนวณให้เอง** | เปิดหน้าคำนวณแล้ว BMR/TDEE, BMI, มาโคร ถูกเติมและคำนวณทันที แคลอรี่ของมาโครใช้ TDEE ไม่ทับค่าที่ผู้ใช้พิมพ์เอง |

ค่าที่ประมาณทั้งหมดติดเครื่องหมาย **≈** ในประวัติและหน้าภาพรวม ค่าที่ผู้ใช้พิมพ์เองจะถูกเก็บตามเดิมเสมอ

## การทดสอบ

ชุดใหม่ **36/36 ผ่าน** โดยเทียบผลคำนวณกับการคิดมือ:

| ทดสอบ | ค่าที่คาด |
|---|---|
| Keytel ชาย HR 150, 70 kg, 25 ปี, 30 นาที | 419 kcal |
| Keytel หญิง (ค่าเดียวกัน) | ตามสูตร |
| วิ่ง 30 นาที ไม่มี HR, 70 kg (MET 9.8) | 343 kcal |
| HR < 90 ใช้ MET แทน / ไม่มีน้ำหนัก = 0 | ✅ |
| เวท 40 นาที RIR 2 / RIR 0 | 172 / 294 kcal |
| Pace 30 นาที 5 กม. / 25 นาที 4.3 กม. / ปั่น 60 นาที 25 กม. | 6:00 / 5:49 /km / 25.0 km/h |
| ระดับจาก HR (อายุ 30, HR พัก 60): 100, 130, 160, 175, 185 | เบา, เบา, ปานกลาง, หนัก, สูงสุด |
| BMR อัตโนมัติ (ชาย 25 ปี 70 kg 175 cm) | ตรงกับสูตร Harris–Benedict |

และทดสอบหน้าจอ: ปุ่ม 👤, บันทึกโปรไฟล์, คำนวณย้อนหลัง, เติมเครื่องคำนวณโดยไม่ทับค่าที่พิมพ์, HR เลือกระดับให้, แคลอรี่ว่างถูกประมาณและติดป้าย, แคลอรี่ที่พิมพ์เองไม่ถูกเปลี่ยน, คอลัมน์ Pace, นาฬิกาพักเริ่มเอง/ปิดได้, session ใหม่มีแคลอรี่, ยอดแคลอรี่หน้าภาพรวมรวมเวทแล้ว, ไม่มี JS error

ชุดเดิมทั้งหมดยังผ่าน: Bluetooth 53 + Strava 19

## ข้อจำกัด

- แคลอรี่เป็นค่าประมาณ คลาดเคลื่อนได้ราว ±20% (สูตร Keytel แม่นที่สุดตอนออกกำลังกายต่อเนื่อง ส่วน MET ไม่รู้ความหนักจริง)
- แคลอรี่เวทคำนวณจากช่วงเวลาที่บันทึก set ถ้าบันทึกทุก set ตอนท้ายทีเดียว แอปจะใช้ 2.5 นาทีต่อ set แทน
- ยังไม่ได้ทำรอบ 3–4 ของแผน (1RM รายท่า, สถิติใหม่, แนะนำน้ำหนักครั้งหน้า, สรุปรายสัปดาห์)
