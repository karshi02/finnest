# รายงาน #14: ปุ่ม "เชื่อมนาฬิกา" บนแถบด้านบน

วันที่: 2026-10-08
Deploy: https://fitt-zeta.vercel.app

## คำขอ

> ปุ่มเชื่อมต่ออยู่ตรงไหน ทำปุ่มเชื่อมต่อดี ๆ ไม่ได้หรือ

ปัญหาเดิม: ปุ่มเชื่อมต่ออยู่ลึก (คาร์ดิโอ > จับเวลา > เลื่อนลงไปที่การ์ด) และเป็นปุ่มเล็กสีน้ำเงิน หาไม่เจอ

## สิ่งที่แก้ (`index.html`, `sw.js`)

| เรื่อง | รายละเอียด |
|---|---|
| ปุ่ม **⌚ เชื่อมนาฬิกา** บนแถบด้านบน | สีขาวเด่น อยู่มุมขวาบน เห็นทุกหน้า กดครั้งเดียวแล้วพาไปหน้าคาร์ดิโอ > จับเวลา และเปิดรายการ Bluetooth ทันที |
| สถานะบนปุ่ม | ยังไม่เชื่อม = สีขาว "⌚ เชื่อมนาฬิกา", กำลังเชื่อม = สีเหลือง "กำลังเชื่อม...", เชื่อมแล้ว = สีเขียว "❤️ 142" (ชีพจรสด) |
| กดตอนเชื่อมแล้ว | พาไปหน้าดูหัวใจสด ไม่เปิดรายการอุปกรณ์ซ้ำ |
| ปุ่มในการ์ด | เปลี่ยนเป็นปุ่มสีแดงขนาดปกติ "⌚ เชื่อมต่อนาฬิกา" |
| มือถือ | แถบด้านบนแบ่งเป็น 2 แถว: แถวบนเป็นโลโก้และปุ่มนาฬิกา แถวล่างเป็นเมนู (เลื่อนซ้ายขวาได้) ปุ่มจึงไม่ล้นจอ |
| `sw.js` | cache `fittrack-v4` |

## การทดสอบ

Chrome headless + นาฬิกา Huawei จำลอง: **20/20 ผ่าน** (ชุดเดิมจาก [FIX-REPORT-08](FIX-REPORT-08.md) 10 ข้อ + ชุดปุ่มใหม่ 10 ข้อ)

| ทดสอบ | ผล |
|---|---|
| ปุ่มแสดงบนแถบด้านบน | ✅ |
| กดแล้วไปหน้าคาร์ดิโอ แท็บจับเวลา และเปิดรายการอุปกรณ์ | ✅ ✅ ✅ |
| กดยกเลิกแล้วปุ่มกลับเป็นสีขาว | ✅ (รอบแรกค้างเป็นสีเหลือง แก้แล้ว) |
| เชื่อมแล้วเป็นสีเขียวและแสดง 142 | ✅ ✅ |
| ปุ่มในการ์ดเปลี่ยนเป็น "ตัดการเชื่อมต่อ" | ✅ |
| กดตอนเชื่อมแล้วไม่เปิดรายการซ้ำ | ✅ |
| ตัดการเชื่อมต่อแล้วกลับเป็นสีขาว | ✅ |

ตรวจหน้าจอที่ความกว้าง 1280 px และ 360 px แล้ว ปุ่มอยู่ในจอทั้งสองขนาด

ยังไม่ได้ทดสอบกับนาฬิกา Huawei จริง (ดูขั้นตอนใน [FIX-REPORT-08](FIX-REPORT-08.md))
