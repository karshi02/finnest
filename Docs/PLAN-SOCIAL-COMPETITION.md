# แผน: จัดอันดับผู้ใช้ การแข่งขัน และนับท่าด้วยกล้อง

วันที่: 2026-10-15
สถานะ: **ร่างแผน ยังไม่ได้ลงมือ**

## คำถาม

> จัดอันดับผู้ใช้งานอื่น ๆ ได้ไหม มีระบบแข่งขัน เช่น วิดพื้นโดยจับท่าทาง มีแรงกิงต่าง ๆ มีการแข่งขันหลายรูปแบบ ทำได้ไหม

## คำตอบสั้น

**ทำได้ทั้งหมด** แต่ต่างจากงานที่ผ่านมามาก ตอนนี้แอปเก็บข้อมูลไว้ในเครื่องผู้ใช้อย่างเดียว ยังไม่มีบัญชีผู้ใช้และไม่มีฐานข้อมูลกลาง การจัดอันดับข้ามผู้ใช้จึงต้องเพิ่ม:

1. **ระบบสมาชิก** (ล็อกอิน) เพื่อรู้ว่าใครเป็นใคร
2. **ฐานข้อมูลกลาง** เก็บผลแข่งขันและอันดับ
3. **การกันโกง** เพราะผลที่ส่งจากเบราว์เซอร์ปลอมแปลงได้

ส่วน**นับวิดพื้นด้วยกล้อง** ทำได้ในเบราว์เซอร์เลย ไม่ต้องมี server และภาพจากกล้องไม่ถูกส่งออกจากเครื่อง จึงแนะนำให้ทำเป็นอย่างแรก

## 1. นับท่าด้วยกล้อง (Pose Detection)

**เทคโนโลยี:** MediaPipe Pose Landmarker (Google) แบบ Web ทำงานในเบราว์เซอร์ด้วย WebAssembly/WebGL ให้จุดบนร่างกาย 33 จุดต่อเฟรม (ไหล่ ศอก ข้อมือ สะโพก เข่า ข้อเท้า)

**วิธีนับวิดพื้น:**
- คำนวณ**มุมศอก** (ไหล่–ศอก–ข้อมือ): ลง < 90° แล้วขึ้น > 160° = นับ 1 ครั้ง (ใช้ 2 เกณฑ์กันการนับซ้ำจากการสั่น)
- ตรวจ**ลำตัวตรง** (ไหล่–สะโพก–ข้อเท้า ≈ 180°): สะโพกตกหรือโด่งเกินไป = ไม่นับ และขึ้นเตือน "สะโพกตก"
- ถ้าลงไม่ลึกพอจะไม่นับ และบอกเหตุผลบนจอ ช่วยมือใหม่ฝึกท่าให้ถูกได้ด้วย

**ท่าอื่นที่ใช้วิธีเดียวกันได้:** สควอท (มุมเข่า), ซิทอัพ/ครันช์ (มุมสะโพก), กระโดดตบ (มือเหนือศีรษะ + ขากาง), แพลงก์ (จับเวลาเฉพาะตอนลำตัวตรง), ลันจ์

**ข้อจำกัด:**
- ต้องวางกล้องให้เห็นทั้งตัวจากด้านข้าง และมีแสงพอ
- มือถือรุ่นกลางได้ประมาณ 15–30 เฟรม/วินาทีกับโมเดลขนาดเล็ก ซึ่งพอสำหรับนับครั้ง
- ความแม่นยำต้องทดสอบกับคนจริงหลายแบบ (รูปร่าง เสื้อผ้า มุมกล้อง)
- ต้องเปิดผ่าน https ซึ่งมีอยู่แล้ว

## 2. การจัดอันดับ (Leaderboard)

| อันดับ | วัดจาก | ความน่าเชื่อถือ |
|---|---|---|
| วิดพื้นใน 60 วินาที | นับด้วยกล้อง | ปานกลาง (ดูข้อ 4 เรื่องกันโกง) |
| วิดพื้น/สควอทได้มากสุดในเซตเดียว | นับด้วยกล้อง | ปานกลาง |
| นาทีคาร์ดิโอรายสัปดาห์ | จาก Strava (นาฬิกา) | **สูง** เพราะข้อมูลมาจากนาฬิกาผ่าน Strava API |
| ระยะวิ่ง/ปั่นรายเดือน | จาก Strava | **สูง** |
| ฝึกต่อเนื่องกี่วัน (streak) | จากการบันทึก | ต่ำ ถ้าไม่ผูกกับ Strava |
| Volume เวทรายสัปดาห์ | กรอกเอง | **ต่ำ** ไม่แนะนำให้จัดอันดับสาธารณะ |

**ให้ยุติธรรม:**
- แบ่งรุ่นตามเพศและช่วงอายุ
- มีทั้งอันดับรวม (ทุกคน) และอันดับเพื่อน/กลุ่ม (เช่น ห้องเรียน คณะ)
- รีเซ็ตรายสัปดาห์และรายเดือน มือใหม่จะได้มีโอกาสขึ้นอันดับ

## 3. รูปแบบการแข่งขัน

| แบบ | ตัวอย่าง |
|---|---|
| **จับเวลา** | วิดพื้นมากที่สุดใน 60 วินาที, สควอทใน 2 นาที |
| **ทำได้มากสุด** | วิดพื้นติดต่อกันจนหมดแรง, แพลงก์นานที่สุด |
| **ท้าดวล 1:1** | ส่งลิงก์ท้าเพื่อน ทำคนละเวลาได้ภายใน 24 ชม. แล้วเทียบผล |
| **เป้าหมายรายสัปดาห์** | คาร์ดิโอครบ 150 นาที, วิดพื้นสะสม 500 ครั้ง |
| **ทีม/กลุ่ม** | ห้อง ก. vs ห้อง ข. รวมคะแนนทั้งทีม |
| **กิจกรรมมีวันเริ่ม–จบ** | ผู้ดูแลสร้างรายการแข่ง เช่น "วิดพื้นชาเลนจ์ คณะวิศวกรรมศาสตร์ เดือนพฤศจิกายน" |
| **ไต่ระดับ** | ภารกิจรายวัน + เหรียญรางวัล (badge) เช่น วิดพื้นครั้งแรกครบ 10 ครั้ง |

## 4. การกันโกง (สำคัญ)

ผลที่นับในเบราว์เซอร์ปลอมได้เสมอ (แก้โค้ด หรือส่งผลตรงไปที่ API) **กันได้ 100% ไม่มี** แต่ลดได้มาก:

- **ตรวจความเป็นไปได้ที่ server:** เช่น วิดพื้นเกิน 80 ครั้ง/นาที หรือทำได้มากขึ้นผิดปกติจากครั้งก่อน = รอตรวจ
- **ส่งร่องรอยท่าทาง:** ส่งมุมศอกตามเวลาแบบย่อ (ไม่ใช่วิดีโอ) server ตรวจได้ว่ามีจังหวะขึ้นลงจริงตามจำนวนครั้ง
- **อันดับสูงต้องมีหลักฐาน:** อันดับ 1–10 ของรายการสำคัญ ให้อัดวิดีโอสั้นแนบ (เลือกได้) และมีป้าย ✔ ยืนยันแล้ว
- **ปุ่มรายงาน** และหน้าผู้ดูแลสำหรับลบผล
- **อันดับที่มาจาก Strava** น่าเชื่อถือกว่า เพราะข้อมูลมาจากนาฬิกา

## 5. สถาปัตยกรรมที่แนะนำ

```
FitTrack (PWA)
 ├─ ข้อมูลส่วนตัว: อยู่ในเครื่องเหมือนเดิม (localStorage)
 ├─ นับท่า: MediaPipe ในเบราว์เซอร์ (วิดีโอไม่ออกจากเครื่อง)
 └─ ส่งเฉพาะผลแข่งขัน ──> Vercel Functions (ตรวจผล/กันโกง) ──> Postgres + Auth
```

- **ฐานข้อมูล + ล็อกอิน:** Supabase (Postgres + Auth + Row Level Security + Realtime สำหรับอันดับสด) ติดตั้งผ่าน Vercel Marketplace ได้ หรือ Neon Postgres + Auth.js ถ้าต้องการแยกส่วน
- **ล็อกอิน:** Google และอีเมล (LINE Login ทำได้ แต่ต้องสมัคร LINE Developers เพิ่ม)
- **ข้อมูลที่ขึ้น server มีแค่:** ชื่อที่แสดง (ไม่ต้องใช้ชื่อจริง), เพศ/ช่วงอายุ (เพื่อแบ่งรุ่น) และผลแข่งขัน ประวัติการฝึกทั้งหมดยังอยู่ในเครื่อง

**ตารางหลัก:** `profiles`, `challenges` (ประเภท, ท่า, กติกา, วันเริ่ม–จบ), `entries` (ผล, ร่องรอยท่า, สถานะตรวจ), `friends`, `teams`, `team_members`, `reports`

## 6. กฎหมายและความเป็นส่วนตัว (PDPA)

- ขอความยินยอมก่อนเก็บข้อมูลขึ้น server และเขียนนโยบายความเป็นส่วนตัว
- ใช้ชื่อเล่นแสดงในอันดับ ไม่ต้องแสดงชื่อจริง
- มีปุ่ม**ลบบัญชีและข้อมูลทั้งหมด**
- ผู้ใช้อายุต่ำกว่า 20 ปี ต้องพิจารณาเรื่องความยินยอมของผู้ปกครอง
- วิดีโอจากกล้องประมวลผลในเครื่อง ไม่อัปโหลด (ยกเว้นผู้ใช้เลือกแนบหลักฐานเอง)
- Vercel แผน Hobby ใช้ได้เฉพาะงานส่วนตัวที่ไม่ใช่เชิงพาณิชย์ ถ้าเปิดให้ลูกค้าใช้จริงควรใช้แผน Pro

## 7. แบ่งเป็นช่วง

| ช่วง | งาน | ต้องมี server | ขนาดประมาณ |
|---|---|---|---|
| **P1** | **นับท่าด้วยกล้อง** (วิดพื้น สควอท แพลงก์) + โหมดท้าตัวเอง 60 วินาที + สถิติส่วนตัว (เก็บในเครื่อง) | ไม่ | 8–12 ชม. |
| P2 | ล็อกอิน + โปรไฟล์สาธารณะ (ชื่อเล่น) + เพื่อน | ใช่ | 8–12 ชม. |
| P3 | อันดับรายสัปดาห์/รายเดือน แบ่งรุ่น + ส่งผลจาก P1 + อันดับจาก Strava + กันโกงขั้นพื้นฐาน | ใช่ | 10–15 ชม. |
| P4 | การแข่งขัน: ท้าดวล, ทีม, กิจกรรมมีวันเริ่ม–จบ, หน้าผู้ดูแล, แจ้งเตือน | ใช่ | 15–25 ชม. |
| P5 | กันโกงขั้นสูง (ตรวจร่องรอยท่า, หลักฐานวิดีโอ, รายงาน) + badge | ใช่ | 8–12 ชม. |

**แนะนำเริ่ม P1** เพราะใช้ได้ทันทีโดยไม่ต้องมีบัญชีหรือค่าใช้จ่าย เห็นผลชัด (เปิดกล้องแล้วนับให้) ใช้ใส่ในเล่มโครงงานได้ และเป็นฐานของการแข่งขันใน P3–P4
