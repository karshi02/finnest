# รายงาน #25: ตัวนับวิดพื้นไม่เสถียร

วันที่: 2026-10-15
Deploy: https://fitt-zeta.vercel.app (cache `fittrack-v13`)

## ปัญหา

เจ้าของแจ้งว่า "ระบบตอนวิดพื้นไม่เสถียร โมเดลไม่ดี"

## สาเหตุที่พบ

1. **ใช้โมเดล lite** ซึ่งเป็นรุ่นเล็กที่สุดและแม่นน้อยที่สุดของ MediaPipe Pose
2. **สลับด้านซ้าย/ขวาได้ทุกเฟรม** ถ้าอีกข้างของร่างกาย (ข้างที่โดนบัง) มีคะแนนมองเห็นสูงกว่านิดเดียว ระบบจะเปลี่ยนไปใช้ข้างนั้นทันที มุมศอกจึงกระโดดไปมา
3. **เฟรมเดียวที่ผิดพลาดทำให้เสียทั้งครั้ง**
   - จุดร่างกายหายไป 1 เฟรม (เช่น แขนบังตัวตอนลงสุด) ⇒ ขึ้น "มองไม่เห็นตัว"
   - ลำตัวดูเหมือนไม่ขนานพื้นแค่ 1 เฟรม ⇒ รีเซ็ตกลับไปรอเริ่มใหม่ ครั้งที่กำลังทำอยู่หายไป
   - มุมสะโพกเพี้ยน 1 เฟรม ⇒ ตัดสินว่า "ลำตัวไม่ตรง" แล้วไม่นับครั้งนั้น
4. **เกณฑ์ศอก ≤ 95° เข้มเกินไป** สำหรับภาพ 2D เพราะมุมที่วัดได้ขึ้นกับมุมกล้อง คนที่ลงถึง 90° จริงอาจวัดได้ 95–100°
5. ถ้าลำตัวไม่ตรงตั้งแต่แรก ระบบจะไม่เริ่มนับเลย และไม่บอกเหตุผล

## สิ่งที่แก้

| เรื่อง | ก่อน | หลัง |
|---|---|---|
| โมเดล | lite | **full** เมื่อใช้ GPU (แม่นกว่าชัดเจน) ถ้าไม่มี GPU ใช้ lite บน CPU เพื่อให้ยังลื่น |
| ความมั่นใจในการติดตามตัว | 0.5 | 0.6 (ติดตามคนเดิมนิ่งขึ้น) |
| เลือกข้างร่างกาย | ทุกเฟรม | ยึดข้างเดิมไว้ เปลี่ยนเฉพาะเมื่ออีกข้างชัดกว่าชัดเจน |
| จุดหาย | หายทันที | ทนได้ 1 วินาทีโดยคงสถานะเดิม |
| ลำตัวไม่ขนานพื้น | รีเซ็ตทันที | ต้องเป็นอย่างนั้นต่อเนื่อง 0.6 วินาทีถึงจะรีเซ็ต |
| ลำตัวไม่ตรง | ตัดสิทธิ์ทันที | ต้องไม่ตรงต่อเนื่อง 0.3 วินาทีถึงจะตัดสิทธิ์ |
| ทำให้ค่านิ่ง | เฉพาะมุมศอก | มุมศอก + มุมลำตัว + ความเอียง |
| เกณฑ์ลง/ขึ้น | ≤ 95° / > 155° | ≤ 100° / > 150° |
| ลำตัวไม่ตรงตั้งแต่แรก | ไม่เริ่มนับ | เริ่มนับ แต่บอกว่า "ครั้งนี้ไม่นับ — ลำตัวไม่ตรง" |

ปรับแบบเดียวกันให้สควอทด้วย คือยึดข้างเดิม ทนจุดหาย และทนหลังก้มชั่วขณะ

ฝั่ง server (`api/_lib/anticheat.js`) ตั้งเกณฑ์ตรวจร่องรอยให้หลวมกว่าในแอปเล็กน้อย (วิดพื้น ≤ 105° / > 145°) เพราะร่องรอยเก็บแค่ 10 ครั้งต่อวินาที อาจพลาดจุดที่ต่ำสุดไป

## การทดสอบ

### กรณีใหม่ (จุดร่างกายสังเคราะห์)

| กรณี | ผล |
|---|---|
| จุดหาย 1 เฟรมแบบสุ่ม | ยังนับได้ 5/5 |
| สะโพกเพี้ยน 1 เฟรม | ยังนับได้ 5/5 |
| ความเอียงเพี้ยน 1 เฟรม | ไม่รีเซ็ต นับได้ 5/5 |
| สองข้างชัดพอกันสลับไปมา | ยึดข้างเดียว นับได้ 5 |
| ลงถึง 98° | นับ |
| สะโพกตกตลอดทั้งครั้ง | ยังไม่นับ |
