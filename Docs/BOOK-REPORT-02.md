# รายงาน #26: อัปเดตเล่มโครงงานให้ตรงกับระบบปัจจุบัน

วันที่: 2026-10-16
ไฟล์: [PROJECT-BOOK.pdf](PROJECT-BOOK.pdf) มี 70 หน้า (เดิม 51 หน้า) · ต้นฉบับอยู่ที่ [book/book.src.html](book/book.src.html) · สร้างด้วย `python book/build.py`

## ปัญหา

เล่มเดิมทำไว้ตั้งแต่ 7 ต.ค. จึงยังไม่มีงานที่ทำหลังจากนั้น ได้แก่
- Strava
- การแก้การเชื่อมต่อนาฬิกา GT 6
- คำนวณอัตโนมัติ
- ชาเลนจ์ที่นับท่าด้วยกล้อง
- บัญชีผู้ใช้ ตารางอันดับ และการแข่งขัน
- ผลการทดสอบชุดใหม่

**บทที่ 2**
- เพิ่ม 2.3.5 แคลอรี่: สมการ Keytel (2.7–2.8) และสูตร MET (2.9)
- เพิ่ม 2.3.6 การคำนวณมุมข้อต่อ (2.10)
- เพิ่มเทคโนโลยี 2.4.9–2.4.13: MediaPipe, MediaRecorder, Strava/OAuth, Supabase, Vercel Functions
- เพิ่ม 2.6 แรงจูงใจด้วยกลไกของเกม (gamification)
- เพิ่ม 2.7 พ.ร.บ. คุ้มครองข้อมูลส่วนบุคคล
- กรอบแนวคิดย้ายเป็น 2.8 และปรับภาพที่ 2.1 กับตาราง 2.2

**บทที่ 3**
- ความเป็นไปได้และความต้องการเพิ่มข้อใหม่
- วาดภาพสถาปัตยกรรม (3.1) ใหม่ทั้งภาพ
- ยูสเคสเพิ่มจาก 11 เป็น 18 รายการ ผู้กระทำเพิ่มจาก 2 เป็น 4
- ตารางใหม่:
  - 3.4 ยูสเคสชาเลนจ์
  - 3.5 ยูสเคสส่งผลเข้าอันดับ
  - 3.9 ข้อมูลชาเลนจ์
  - 3.10 ตารางในฐานข้อมูล
- ภาพใหม่:
  - 3.5 แผนภาพสถานะตัวนับวิดพื้น
  - 3.6 ผังงานตรวจผลก่อนขึ้นอันดับ
- เพิ่มข้อกำหนด F14–F22 เครื่องมือ และแผนงาน
- เลขตารางเดิมถูกเลื่อน และแก้การอ้างอิงในเนื้อหาให้ตรงแล้ว

**บทที่ 4**
- เพิ่ม 4.1.10–4.1.16 พร้อมภาพหน้าจอใหม่ 8 ภาพ (ภาพที่ 4.12–4.19)
- ตัวอย่างคำนวณแคลอรี่ 407 kcal ตรวจกับสมการ 2.7 แล้วตรงกัน
- ตารางทดสอบใหม่:
  - 4.4 ชาเลนจ์ 36/36
  - 4.5 บัญชี อันดับ และการแข่งขัน 135/135
  - 4.6 สรุป 293/293
- เขียนผลที่ลองกับ GT 6 จริง
- ตารางความพึงพอใจเปลี่ยนเป็นตาราง 4.7 และเพิ่มข้อ 11–12
