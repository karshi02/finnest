# รายงาน #4: เชื่อมต่อสมาร์ทวอทช์ (HR สดผ่าน Bluetooth) + แผน Strava

วันที่: 2026-10-05
Branch: `fix/review-rounds-1-4`
สถานะ: **HR สดเสร็จและทดสอบผ่าน (ด้วยอุปกรณ์จำลอง) ยังไม่ได้ commit** ส่วน Strava เป็นแผนที่รอข้อมูลจากคุณ

## คำขอ

> ถ้าอยากให้ระบบนี้ซิงก์กับสมาร์ทวอทช์ได้ไหม (ใช้ Android)

## เลือกทำอะไร และทำไม

แอปนี้เป็นเว็บแอป (PWA) จึงอ่านข้อมูลจาก Health Connect ของ Android โดยตรงไม่ได้ สิ่งที่ทำได้ทันทีโดยไม่ต้องมี server คือ **Web Bluetooth** ใน Chrome Android: เชื่อมกับนาฬิกาหรือสายคาดอกที่ส่งสัญญาณ HR แบบมาตรฐาน (Bluetooth Heart Rate Service) แล้วอ่านหัวใจแบบ real-time

ส่วนการซิงก์ประวัติการออกกำลังกายย้อนหลังต้องผ่าน Strava ซึ่งต้องมี server และบัญชี Strava ของคุณ จึงแยกเป็นแผนไว้ท้ายเอกสาร

| ส่วน | รายละเอียด |
|---|---|
| การ์ด "⌚ หัวใจสดจากนาฬิกา" | ปุ่ม "เชื่อมต่อ" เปิดหน้าเลือกอุปกรณ์ของ Chrome (แสดงเฉพาะอุปกรณ์ที่ส่ง HR) |
| HR สด | ตัวเลขใหญ่กระพริบตามค่าที่เข้ามา อ่านได้ทั้งแบบ 8 บิตและ 16 บิตตามมาตรฐาน และไม่นับค่า 0 (ตอนนาฬิกายังไม่แนบผิว) |
| โซนตอนนี้ | แสดง Zone 1–5 พร้อมสี ใช้สูตร Karvonen เดียวกับแท็บโซนหัวใจ |
| เฉลี่ย / สูงสุด | นับ **เฉพาะตอน Stopwatch เดินอยู่** และรีเซ็ตพร้อม stopwatch |
| ปุ่ม "💾 บันทึกเป็นคาร์ดิโอ" | หยุดนาฬิกา แล้วเติมระยะเวลา (นาที) กับ **HR เฉลี่ยจากนาฬิกา** ลงในฟอร์มบันทึกให้ ผู้ใช้แค่ตรวจแล้วกดบันทึก |
| สัญญาณหลุด | ลองเชื่อมใหม่เอง 3 ครั้ง (รอ 1, 2, 3 วินาที) ถ้ากด "ตัดการเชื่อมต่อ" เองจะไม่เชื่อมใหม่ |
| จำโปรไฟล์ | อายุและ HR พักที่กรอกในแท็บโซนหัวใจถูกบันทึกลง `state.profile` แล้ว รีโหลดก็ไม่ต้องกรอกใหม่ และติดไปกับ Export/Import ด้วย (ตรวจช่วงค่าก่อนเก็บ) |
| ไม่รองรับ | iPhone หรือเบราว์เซอร์อื่นจะแจ้งให้ใช้ Chrome บน Android หรือคอม ถ้าเปิดแบบ `file://` หรือ http ที่ไม่ใช่ localhost จะแจ้งให้เปิดผ่าน https |
| วิธีใช้ | มีหัวข้อ "ใช้กับนาฬิกาอะไรได้บ้าง?" ที่กดเปิดดูได้ อธิบายว่ายี่ห้อไหนต้องเปิดโหมดอะไร |

### แก้เพิ่ม (บั๊กเดิมที่เจอระหว่างทดสอบ)

- **ตัวเลข Stopwatch ล้นจอมือถือ:** จอ 360px ถูกดันกว้างเป็น 383px ตั้งแต่โค้ดต้นฉบับ แก้ด้วยการใช้ `clamp()` ให้ตัวอักษรย่อตามความกว้างจอ
- จัดหน้าโซนหัวใจใหม่: แยกการสร้างโซนเป็นฟังก์ชัน `buildZones()` ให้ตารางโซนกับ HR สดใช้สูตรเดียวกัน

## นาฬิกาที่ใช้ได้

| ยี่ห้อ | ใช้ได้ไหม | ต้องทำอะไร |
|---|---|---|

| Amazfit / Zepp | บางรุ่น | เปิด "Heart rate sharing" หรือ "Discoverable" |
| สายคาดอก HR ทั่วไป (Polar H10, Garmin HRM, Coospo ฯลฯ) | ✅ | ใส่แล้วกดเชื่อมต่อได้เลย |
| Galaxy Watch, Pixel Watch | ⚠️ | ไม่ส่งสัญญาณแบบนี้เอง ต้องลงแอปเสริมบนนาฬิกาที่ส่ง HR ผ่าน BLE |
| Xiaomi / Huawei | ไม่แน่นอน | บางรุ่นมีโหมดแชร์ HR ต้องลองดู |

## การทดสอบ

ทดสอบใน Chrome ด้วย **อุปกรณ์ Bluetooth จำลอง** ที่ส่งข้อมูลรูปแบบเดียวกับมาตรฐาน Heart Rate Service (ชื่ออุปกรณ์สมมติเป็น "Forerunner 265")

| ทดสอบ | ผล |
|---|---|
| ไม่มี Bluetooth (เช่น iPhone) แสดงข้อความแนะนำ | ✅ |
| กรอกโซนหัวใจแล้วจำอายุ/HR พัก, รีโหลดแล้วยังอยู่ | ✅ |
| ขอเฉพาะอุปกรณ์ที่มี `heart_rate` service | ✅ |
| เชื่อมต่อแล้วแสดงชื่ออุปกรณ์ และปุ่มเปลี่ยนเป็น "ตัดการเชื่อมต่อ" | ✅ |
| อ่านค่า HR แบบ 8 บิต / 16 บิต | ✅ |
| โซนถูกต้อง: 100 = ต่ำกว่า Z1, 130 = Z1, 160 = Z3, 185 = Z5 (อายุ 30, HR พัก 60) | ✅ |
| เฉลี่ย/สูงสุดนับเฉพาะช่วงจับเวลา (ค่าที่ส่งก่อนกดเริ่มไม่ถูกนับ) | ✅ |
| "บันทึกเป็นคาร์ดิโอ" เติม 25 นาที + HR 150 และหยุดนาฬิกา | ✅ |
| สัญญาณหลุดแล้วเชื่อมใหม่เอง / กดตัดเองแล้วไม่เชื่อมใหม่ | ✅ |
| จอ 360px ไม่มี scroll แนวนอน | ✅ |
| ไม่มี JS error | ✅ |
| ชุดทดสอบเดิม (31 + วิดีโอ 8 + autoplay 3 + file:// 1) | ✅ ทั้งหมด |

**ยังไม่ได้ทดสอบกับนาฬิกาจริง** เพราะเครื่องที่ทดสอบไม่มีอุปกรณ์ Bluetooth HR ต้องลองบน Android + Chrome กับนาฬิกาของคุณ และต้องเปิดแอปผ่าน **https** (หลัง deploy) หรือ `http://localhost` เท่านั้น

## แผนถัดไป: ซิงก์ประวัติผ่าน Strava (ยังไม่ได้ทำ)

**ได้อะไร:** วิ่ง, ปั่น, ว่ายน้ำ ที่บันทึกในนาฬิกา (ซึ่งซิงก์เข้า Strava อยู่แล้ว) จะเข้ามาในประวัติคาร์ดิโอเอง พร้อมเวลา, ระยะ, HR เฉลี่ย และแคลอรี่ ไม่ต้องพิมพ์เอง

**ต้องมี:**
1. บัญชี Strava ที่นาฬิกาซิงก์เข้าอยู่แล้ว
2. สร้าง "API Application" ที่ strava.com/settings/api (ฟรี) เพื่อให้ได้ Client ID กับ Client Secret
3. Server เล็ก ๆ ไว้เก็บ Client Secret และแลก token เพราะห้ามใส่ secret ไว้ในหน้าเว็บ ใช้ Cloudflare Worker แบบฟรีได้

**ขั้นตอนโดยประมาณ:**

| # | งาน | แรงที่ใช้ |
|---|---|---|
| 1 | Cloudflare Worker: endpoint `/strava/token` สำหรับแลก code เป็น token และ refresh token | M |
| 2 | ปุ่ม "เชื่อมต่อ Strava" ในแอป (OAuth redirect) แล้วเก็บ token ไว้ในเครื่อง | M |
| 3 | ปุ่ม "ดึงกิจกรรมล่าสุด" ใช้ `GET /athlete/activities` แล้วแปลงเป็นรายการคาร์ดิโอ (กันซ้ำด้วย Strava activity id) | M |
| 4 | ซิงก์อัตโนมัติตอนเปิดแอป (ดึงเฉพาะกิจกรรมหลังครั้งล่าสุด) | S |
| 5 | ทดสอบ + เขียนรายงาน | S |

**ข้อจำกัด:**
- เวทเทรนนิ่งจาก Strava มีแค่เวลากับ HR ไม่มีท่า, น้ำหนัก หรือ reps
- Strava จำกัดจำนวนครั้งที่เรียก API ต่อวัน ซึ่งพอสำหรับใช้คนเดียว
- เงื่อนไขการใช้งาน API ของ Strava ห้ามแสดงข้อมูลของผู้ใช้คนหนึ่งให้คนอื่นเห็น ใช้ส่วนตัวไม่มีปัญหา

## สิ่งที่ต้องทำต่อ (ฝั่งคุณ)

1. บอกยี่ห้อ/รุ่นนาฬิกา เพื่อยืนยันว่าส่ง HR ผ่าน Bluetooth ได้ไหม และต้องเปิดเมนูไหน
2. Deploy (หรือเปิดผ่าน `http://localhost:8080` บนคอมที่มี Bluetooth) แล้วลองกด "เชื่อมต่อ" กับนาฬิกาจริง
3. ถ้าจะทำ Strava: ยืนยันว่ามีบัญชี Strava และนาฬิกาซิงก์เข้าไปอยู่แล้ว
