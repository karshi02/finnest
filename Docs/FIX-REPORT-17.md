# รายงาน #24: P2–P5 บัญชีผู้ใช้ อันดับ การแข่งขัน และกันโกง

Deploy: https://fitt-zeta.vercel.app (cache `fittrack-v12`)
ทำตาม: [PLAN-SOCIAL-COMPETITION.md](PLAN-SOCIAL-COMPETITION.md) ช่วง P2 ถึง P5 ตามที่เจ้าของสั่ง "ทำถึง P5"

## ภาพรวม

เพิ่มหน้าใหม่ **🥇 อันดับ** (เมนูสุดท้าย) และระบบหลังบ้านบน Supabase

```
เบราว์เซอร์ ── /api/social (Vercel Function) ── Supabase (Postgres + Auth + Storage, สิงคโปร์)
```

- เบราว์เซอร์**ไม่คุยกับฐานข้อมูลตรง** ทุกคำขอผ่าน `api/social.js` ซึ่งตรวจสิทธิ์และตรวจผลก่อนเขียน
- ทุกตารางเปิด RLS โดยไม่มี policy ให้ anon หรือ authenticated ฟังก์ชันอันดับให้สิทธิ์เฉพาะ service role ดังนั้นถึงมีคนได้ anon key ไปก็อ่านหรือเขียนข้อมูลไม่ได้
- ไม่ใช้ npm package เพิ่ม เพราะเรียก Supabase ผ่าน HTTP ตรง ๆ (`api/_lib/supa.js`)
- ค่าลับ (service role key) อยู่ใน env ของ Vercel ที่ได้จากการเชื่อม Supabase ผ่าน Vercel Marketplace ไม่อยู่ใน git และไม่อยู่ในหน้าเว็บ

## P2 บัญชีผู้ใช้

| เรื่อง | ทำอย่างไร |
|---|---|
| สมัคร/เข้าสู่ระบบ | ใช้**ชื่อผู้ใช้ + รหัสผ่าน** (8–72 ตัว) ไม่ขออีเมล ระบบสร้างบัญชีใน Supabase Auth ด้วยอีเมลภายใน `<username>@users.fittrack.invalid` ซึ่งไม่มีใครใช้ส่งเมลได้ |
| ข้อมูลที่เก็บ | ชื่อผู้ใช้, ชื่อที่แสดง, เพศ และช่วงอายุ (ทั้งสองไม่บังคับ ใช้แยกอันดับ), เวลาที่ยินยอม |
| PDPA | ต้องติ๊กยินยอมก่อนสมัคร ถ้าอายุต่ำกว่า 18 ต้องติ๊กว่าผู้ปกครองยินยอมด้วย และ**ลบบัญชีได้เอง** (ลบทุกตาราง + วิดีโอ + ดวลที่สร้าง) |
| เซสชัน | access token + refresh token เก็บใน localStorage ต่ออายุเองเมื่อใกล้หมดหรือโดนปฏิเสธ ไม่เก็บรหัสผ่าน และไม่รวมในไฟล์ Export |
| กันสแปม | สมัครได้ 5 บัญชีต่อ IP ต่อวัน (เก็บเป็น hash ไม่เก็บ IP จริง) |
| เพื่อน | แลก**รหัสเพื่อน** 8 ตัว เพิ่มแล้วเป็นเพื่อนกันทั้งสองฝั่ง ลบได้ |
| ทีม | สร้างทีมแล้วได้**รหัสชวน** หนึ่งคนอยู่ได้ทีมเดียว ทีมละไม่เกิน 50 คน ถ้าคนสุดท้ายออก ทีมจะถูกลบ |
| แก้ไขข้อมูล | ชื่อที่แสดง เพศ ช่วงอายุ |

แผนเดิมแนะนำล็อกอินด้วย Google + อีเมล แต่ตอนนี้ใช้ชื่อผู้ใช้ + รหัสผ่านไปก่อน เหตุผลมีสองข้อ: ไม่ต้องสร้าง Google OAuth app และไม่ต้องเก็บอีเมลเลย (ตรงกับ PDPA ที่ให้เก็บน้อยที่สุด) จะเพิ่ม Google ทีหลังก็ได้

## P3 อันดับ

- เลือกรายการได้: วิดพื้น, สควอท, แพลงก์ (ทุกโหมด), **คาร์ดิโอนาที/สัปดาห์** และ**ระยะทาง กม./สัปดาห์**
- ช่วงเวลา: สัปดาห์นี้ / เดือนนี้ / ตลอดกาล (ตัดรอบวันจันทร์ 00:00 และวันที่ 1 ตามเวลาไทย)
- กรองได้: ทุกคน / เพื่อน / ทีม, เพศ, ช่วงอายุ
- นับเฉพาะ**ผลที่ดีที่สุดของแต่ละคน**และเฉพาะผลที่ผ่านการตรวจ บัญชีที่ถูกระงับจะไม่แสดง
- ผลของเราเองมีพื้นสีฟ้า มี 🎥 ถ้าแนบวิดีโอ และมีปุ่ม 🚩 ไว้รายงานผลของคนอื่น
- **ส่งผลจากหน้าชาเลนจ์อัตโนมัติ** เมื่อจบชาเลนจ์ (ปิดได้ในหน้าบัญชี) ประวัติชาเลนจ์มีคอลัมน์ "อันดับ" บอกสถานะ ✅ ขึ้นอันดับ, ⏳ รอตรวจ, ❌ ไม่ผ่าน หรือปุ่ม 📤 ให้ส่งเอง
- **คาร์ดิโอจาก Strava**: server ดึงกิจกรรมสัปดาห์นี้จาก Strava เองด้วย token ของผู้ใช้ ไม่เชื่อตัวเลขที่เบราว์เซอร์ส่งมา และไม่นับกิจกรรมที่พิมพ์เอง (manual) ปุ่มนี้ใช้ได้เมื่อตั้งค่า Strava เสร็จ (ดูรายงาน #16)

### กันโกงขั้นพื้นฐาน (ตรวจที่ server ทุกครั้ง)

| ตรวจ | ผล |
|---|---|
| เกินที่เป็นไปได้ (เช่น วิดพื้น 60 วินาที > 100, แพลงก์ > 1 ชม.) / โหมด 60 วินาทีแต่ใช้เวลาไม่ใกล้ 60 / ค้างแพลงก์นานกว่าเวลาทั้งหมด | **ไม่รับ** |
| ส่งเกิน 30 ครั้งต่อวัน | ไม่รับ |
| จำนวนครั้งไม่ตรงกับ**ร่องรอยมุมข้อต่อ** (server นับซ้ำจากร่องรอยด้วยเกณฑ์เดียวกับในแอป ยอมให้ต่างได้ 10%) | รอตรวจ |
| ร่องรอยสั้นกว่าครึ่งของเวลาที่บอก | รอตรวจ |
| ผลสูงผิดปกติ (เช่น วิดพื้น 60 วินาที > 70) | รอตรวจ |

"รอตรวจ" แปลว่าเก็บผลไว้แต่ยังไม่ขึ้นอันดับจนกว่าผู้ดูแลจะอนุมัติ

## P4 การแข่งขัน

| แบบ | วิธีเล่น | ตัดสิน |
|---|---|---|
| ⚔️ **ดวล 1:1** | เลือกท่าแล้วกด "สร้างรหัสท้าดวล" ส่งรหัสให้เพื่อน เพื่อนกดรับ แล้วแข่งกัน 24 ชม. (รหัสหมดอายุใน 7 วัน รับหรือปฏิเสธได้) | ผลที่ดีที่สุดในช่วงนั้น |
| 🛡️ **ทีม vs ทีม** | ใส่รหัสทีมคู่แข่ง แล้วเลือก 3, 7 หรือ 14 วัน | ผลรวมของผลที่ดีที่สุดของสมาชิกแต่ละคน |
| 🎪 **อีเวนต์** | ผู้ดูแลสร้าง กำหนดวันเริ่ม–จบ ผู้ใช้กด "เข้าร่วม" | แสดง 10 อันดับแรก |

- ผลชาเลนจ์**นับเข้าการแข่งที่เราอยู่และกำลังแข่งอยู่โดยอัตโนมัติ** server เป็นคนเลือกการแข่งเอง เบราว์เซอร์เลือกไม่ได้
- ปุ่ม "📷 ไปทำชาเลนจ์" พาไปหน้ากล้องโดยตั้งท่าและโหมดให้แล้ว
- เมื่อหมดเวลา ระบบปิดการแข่งเองตอนที่มีคนเปิดดู (จึงไม่ต้องมี cron) แล้วประกาศผู้ชนะ/ทีมชนะ หรือเสมอ
- **แจ้งเตือนในแอป**: ตอนเปิดแอป ถ้าการแข่งที่เราเล่นจบแล้วและเรายังไม่เคยดูผล จะมีจุดเหลืองที่เมนู 🥇 และ toast บอก เข้าหน้าอันดับแล้วจะบอกว่า "คุณชนะ" หรือ "คุณแพ้" และไม่แจ้งซ้ำ
- **ผู้ดูแล** กำหนดได้ 2 ทาง: ตั้ง env `ADMIN_USERNAMES=ชื่อ1,ชื่อ2` ใน Vercel หรือตั้ง `is_admin = true` ในตาราง profiles

## P5 กันโกงขั้นสูง + เหรียญ

- **ติด 10 อันดับแรกต้องมีวิดีโอ**: ถ้าผลเท่ากับหรือดีกว่าอันดับที่ 10 แต่ไม่มีวิดีโอ ผลจะรอตรวจ
- **ดีขึ้นแบบก้าวกระโดด** (ดีกว่าสถิติเดิมเกิน 1.5 เท่า + 5) ก็จะรอตรวจ
- **อัดวิดีโอหลักฐาน** (ติ๊กเองในหน้าชาเลนจ์ ค่าเริ่มต้นคือปิด): ใช้ MediaRecorder อัด 300 kbps (ประมาณ 2.3 MB ต่อนาที) และ**ส่งขึ้นเฉพาะผลที่ต้องตรวจ** อัปโหลดตรงไป Supabase Storage ด้วย signed upload URL ใช้ได้ครั้งเดียว bucket `proofs` เป็นแบบส่วนตัว (จำกัด 25 MB เฉพาะ webm/mp4) และดูได้เฉพาะเจ้าของกับผู้ดูแลผ่านลิงก์ชั่วคราว 10 นาที ถ้าแนบวิดีโอแล้วไม่เหลือข้อสงสัยอื่น ผลจะขึ้นอันดับทันที
- **รายงาน 🚩**: รายงานผลของคนอื่นได้ คนละครั้งต่อผล ถ้ามีคนรายงาน 3 คน ผลจะถูกซ่อนจนกว่าผู้ดูแลจะตรวจ
- **หน้าผู้ดูแล** (แสดงเฉพาะผู้ดูแล):
  - คิวผลรอตรวจพร้อมเหตุผล (ป้ายสีส้ม)
  - **กราฟมุมข้อต่อ**ตลอดชาเลนจ์ (เห็นจังหวะขึ้น–ลงจริง)
  - วิดีโอ
  - ปุ่มอนุมัติ / ไม่อนุมัติ / ระงับบัญชี
  - รายการรายงาน
  - ฟอร์มสร้างอีเวนต์
- **เหรียญ 10 แบบ**:

  | เหรียญ | ได้เมื่อ |
  |---|---|
  | ส่งผลครั้งแรก | ส่งผลเข้าอันดับครั้งแรก |
  | วิดพื้น 20 | วิดพื้นได้ 20 ครั้ง |
  | วิดพื้น 50 | วิดพื้นได้ 50 ครั้ง |
  | สควอท 50 | สควอทได้ 50 ครั้ง |
  | แพลงก์ 1 นาที | ค้างแพลงก์ได้ 1 นาที |
  | แพลงก์ 3 นาที | ค้างแพลงก์ได้ 3 นาที |
  | เข้าร่วมทีม | อยู่ในทีม |
  | มีเพื่อน 3 คน | มีเพื่อนครบ 3 คน |
  | ชนะการดวล | ชนะดวล 1:1 |
  | ติด 3 อันดับแรกในอีเวนต์ | จบอีเวนต์ใน 3 อันดับแรก |

  เหรียญจะเด้ง toast ตอนได้ และแสดงในหน้าบัญชี

## ความปลอดภัย

| เรื่อง | การป้องกัน |
|---|---|
| คำขอจากเว็บอื่น | รับเฉพาะ Origin ของเว็บนี้และ localhost:8080 |
| แทรกเงื่อนไขในคำค้นฐานข้อมูล | ค่าที่ผู้ใช้ส่งมาถูก encode ทุกตัวก่อนใส่ในตัวกรอง PostgREST |
| สวมรอยเป็นคนอื่น | ทุกคำขอที่ต้องล็อกอิน server ตรวจ token กับ Supabase Auth ก่อน แล้วใช้ id จาก token ไม่ใช้ id ที่ client ส่งมา |
| แก้/ดูผลหรือวิดีโอของคนอื่น | ตรวจเจ้าของทุกครั้ง (`proof_url` และ `proof_done` ต้องเป็นผลของตัวเอง, `path` ต้องตรงรูปแบบ `<user>/<entry>.webm`) |
| ชื่อที่แสดงมี HTML | escape ทุกจุดที่แสดง (ทดสอบด้วย `<img onerror>`) |
| error ภายใน | ส่งกลับแค่ "ระบบขัดข้อง" รายละเอียดอยู่ใน log ของ Vercel เท่านั้น |
| สองคนกดรับดวลพร้อมกัน | อัปเดตแบบมีเงื่อนไข `status=open` คนที่สองจะได้ "มีคนรับไปแล้ว" |

## ข้อจำกัดที่รู้

- Supabase จำกัดการล็อกอินตาม IP ของผู้เรียก ซึ่งในระบบนี้คือ IP ของ Vercel จึงใช้ร่วมกันทุกคน ถ้ามีผู้ใช้พร้อมกันเยอะมากอาจเจอ "ลองบ่อยเกินไป" (สำหรับกลุ่มเพื่อนหรือห้องเรียนไม่มีปัญหา)
- แจ้งเตือนเป็นแบบในแอป (ตอนเปิดแอปหรือเปิดหน้า) ยังไม่มี push notification ตอนปิดแอป
- กันโกงทำให้โกงยากขึ้นมาก แต่ไม่ได้ทำให้โกงไม่ได้ 100% เช่น คนที่เขียนร่องรอยปลอมให้สมจริงได้ จึงมีวิดีโอ รายงาน และผู้ดูแลเป็นด่านสุดท้าย
- ปุ่มคาร์ดิโอจาก Strava ยังรอเจ้าของใส่คีย์ Strava (รายงาน #16)

## ต้องทำต่อ (เจ้าของ)

1. ตั้งตัวเองเป็นผู้ดูแล: สมัครบัญชีในเว็บก่อน แล้วรัน
   ```
   vercel env add ADMIN_USERNAMES production
   ```
   ใส่ชื่อผู้ใช้ของตัวเอง แล้ว `vercel --prod`
2. (ไม่บังคับ) ใส่คีย์ Strava เพื่อเปิดอันดับคาร์ดิโอ
