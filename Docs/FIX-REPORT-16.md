# รายงาน #23: P1 นับท่าด้วยกล้อง (หน้า 🏆 ชาเลนจ์)

วันที่: 2026-10-15
Deploy: https://fitt-zeta.vercel.app (cache `fittrack-v11`)
ทำตาม: [PLAN-SOCIAL-COMPETITION.md](PLAN-SOCIAL-COMPETITION.md) ช่วง P1 ใช้ท่าตามที่แนะนำ: วิดพื้น + สควอท + แพลงก์

## สิ่งที่ทำ

หน้าใหม่ **🏆 ชาเลนจ์** (เมนูบนสุด) เปิดกล้องแล้วนับท่าให้ ใช้ **MediaPipe Pose Landmarker** (`@mediapipe/tasks-vision` 1.1.1, โมเดล lite) ทำงานในเบราว์เซอร์ **ภาพจากกล้องไม่ถูกส่งออกจากเครื่อง**

| ท่า | นับเมื่อ | ไม่นับเมื่อ (และบอกเหตุผลบนจอ) |
|---|---|---|
| วิดพื้น | มุมศอก ≤ 95° แล้วเหยียดกลับ > 155° ลำตัว (ไหล่–สะโพก–ข้อเท้า) ≥ 150° และขนานพื้น | ลงไม่ลึก → "ลงให้ลึกกว่านี้", สะโพกตก/โด่ง → "ครั้งนี้ไม่นับ — ลำตัวไม่ตรง", ยืนงอแขน → ไม่นับ |
| สควอท | มุมเข่า ≤ 100° แล้วยืนกลับ > 160° อกตั้ง | ย่อครึ่งเดียว → "ย่อลงอีกนิด", หลังก้มมาก → ไม่นับ |
| แพลงก์ | จับเวลาเฉพาะตอนลำตัวตรง (≥ 160°) และขนานพื้น | สะโพกตก → นาฬิกาหยุด |

- โหมด: มากสุดใน 60 วินาที / ทำได้มากสุด / แพลงก์ค้างได้นานสุด
- นับถอยหลัง 3 วินาทีก่อนเริ่ม และมีเสียงทุกครั้งที่นับได้
- เลือกด้านของร่างกายที่กล้องเห็นชัดกว่าเอง, ปรับมุมตามสัดส่วนภาพ, ทำให้ค่ามุมนิ่ง (กันการนับซ้ำจากการสั่น)
- วาดโครงร่างกายทับวิดีโอ
- **สถิติส่วนตัว**ของแต่ละท่า/โหมด และ**ประวัติ** (ลบได้) เก็บในเครื่อง (`challengeLog`) และติดไปกับไฟล์ Export
- เก็บ**ร่องรอยมุม 10 ครั้ง/วินาที** (ไม่ใช่วิดีโอ) ไว้ใช้ตรวจกันโกงตอนส่งแข่งใน P3/P5
- ออกจากหน้าแล้วปิดกล้องเอง, ผลเป็น 0 ไม่บันทึก
- ข้อความ error ชัดเจน: ไม่อนุญาตกล้อง / ไม่มีกล้อง / ออฟไลน์ (ต้องต่อเน็ตครั้งแรกเพื่อโหลดตัวจับท่า)

## การทดสอบ

| ชุด | ผล |
|---|---|
| ตัวนับด้วยจุดร่างกายสังเคราะห์: วิดพื้นถูก 5 ครั้ง = 5, ลงตื้น = 0, สะโพกตก = 0, มองไม่เห็นตัว = 0, ยืนงอแขน = 0, มุมสั่น ±5° ยังนับถูก, สควอทลึก 3 = 3, ย่อครึ่ง = 0, หลังก้ม = 0, แพลงก์ 10 วินาที ≈ 10.0, สะโพกตกกลางทางนาฬิกาหยุด, หน้าจอ, สถิติ, ประวัติ, ตรวจข้อมูลนำเข้า | 22/22 ✅ |

## ยังไม่ได้ทดสอบ

- **กับคนจริงหน้ากล้อง:** เกณฑ์มุม (95°/155°, 100°/160°) ตั้งตามท่ามาตรฐาน อาจต้องปรับหลังลองกับผู้ใช้จริงหลายคน
- ความเร็วบนมือถือรุ่นต่าง ๆ (ใช้ GPU ถ้ามี ไม่มีจะใช้ CPU)
