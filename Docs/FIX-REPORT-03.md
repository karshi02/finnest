## อาการ

กดการ์ดท่าแล้ว แทนที่วิดีโอจะเล่น กลับขึ้นข้อความ "เล่นวิดีโอนี้ในแอปไม่ได้ — ดูบน YouTube ↗" ทุกท่า

## สาเหตุ

ผู้ใช้เปิดแอปด้วยการดับเบิลคลิกไฟล์ `index.html` ทำให้หน้าเว็บเปิดแบบ `file://` แต่ YouTube ไม่ยอมเล่นวิดีโอที่ฝังในหน้าที่ไม่มี origin หรือ referrer แบบ `http(s)` และจะส่ง error กลับมา แอปจึงแสดงข้อความ fallback

- ทดสอบซ้ำด้วย Chrome แล้ว: เปิดแบบ `file://` ได้ error ทุกท่า ส่วนเปิดผ่าน `http://localhost:8080` วิดีโอเล่นเองได้ (player state = PLAYING)
- ชุดทดสอบในรายงาน #2 ไม่เจอปัญหานี้ เพราะทดสอบผ่าน `http://localhost` อย่างเดียว

**โค้ดเล่นวิดีโอไม่มีบั๊ก** ปัญหาอยู่ที่วิธีเปิดแอป ซึ่งจะไม่เกิดเมื่อแอปอยู่บนเว็บจริง (GitHub Pages เป็น `https`) หรือเปิดผ่าน local server

## สิ่งที่แก้

`index.html` ใน `openExerciseModal`: ถ้าเปิดแบบ `file://` จะไม่พยายามโหลด player แล้ว แต่แสดงสาเหตุให้ชัดแทน

> วิดีโอเล่นไม่ได้เมื่อเปิดไฟล์ตรงจากเครื่อง (file://)
> ให้เปิดผ่านเว็บ (https) หรือ local server เช่น http://localhost
> ดูบน YouTube ↗

## วิธีเปิดแอปในเครื่องให้วิดีโอเล่นได้

```bash
cd C:\Users\karsh\Desktop\fitt
python -m http.server 8080
```

จากนั้นเปิด `http://localhost:8080` (service worker และการแจ้งเตือนก็ต้องเปิดแบบนี้เช่นกัน)
