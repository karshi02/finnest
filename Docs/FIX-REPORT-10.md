# รายงาน #15: ตรวจปัญหาในแอปและวิธีเปิดส่ง HR บน Huawei WATCH GT 6

วันที่: 2026-10-08
Deploy: https://fitt-zeta.vercel.app

## คำขอ

> หาอุปกรณ์ไม่เจอ เชื่อมต่อตรง ๆ ได้ไหม ทำให้หน่อย

นาฬิกาของผู้ใช้: HUAWEI WATCH GT 6 (ATM-B19), HarmonyOS 6.1.0, ชื่อ Bluetooth `HUAWEI WATCH GT 6-55C`

## คำตอบเรื่อง "เชื่อมตรง ๆ"

เชื่อมด้วย MAC address ไม่ได้ Web Bluetooth ไม่มี API ให้หน้าเว็บเชื่อมจาก MAC (เพื่อความปลอดภัย) ต้องเลือกจากหน้าต่างของ Chrome เท่านั้น แอปค้นชื่อที่ขึ้นต้นด้วย `HUAWEI` อยู่แล้ว ([FIX-REPORT-08](FIX-REPORT-08.md)) ถ้าไม่เห็นในรายการ แปลว่านาฬิกายังไม่ได้ส่งสัญญาณ หรือ Bluetooth ฝั่งคอม/มือถือใช้ไม่ได้

## สิ่งที่แก้ (`index.html`, `sw.js`)

เมื่อหาไม่เจอหรือเชื่อมไม่สำเร็จ แอปจะแสดงกล่อง **ตรวจเครื่องนี้** ใต้ปุ่มเชื่อมต่อ:

| ตรวจ | วิธี |
|---|---|
| เบราว์เซอร์รองรับ Bluetooth | มี `navigator.bluetooth` และไม่ใช่ Huawei Browser / MIUI Browser / เบราว์เซอร์ใน Facebook, LINE |
| เปิดผ่าน https | `window.isSecureContext` |
| Bluetooth ของเครื่องเปิดอยู่ | `navigator.bluetooth.getAvailability()` (แสดงเฉพาะเมื่อเบราว์เซอร์รองรับ) |

และแสดงขั้นตอนบนนาฬิกา Huawei: ตั้งค่า > HR Data Broadcasts > เปิดค้างไว้ > กดเชื่อมต่อ > เลือก HUAWEI WATCH พร้อมคำแนะนำแยกตามเครื่อง:
- มือถือ: เปิดตำแหน่ง (GPS), ให้สิทธิ์ Chrome, ปิด Huawei Health ชั่วคราว
- คอม: ห้ามจับคู่นาฬิกาใน Windows

กล่องนี้จะซ่อนเองเมื่อเชื่อมสำเร็จ `sw.js` เปลี่ยนเป็น cache `fittrack-v5`

## ยังไม่รู้

- **ยังไม่ยืนยันว่า WATCH GT 6 มีเมนู HR Data Broadcasts** เอกสารของ Huawei ([ลิงก์](https://consumer.huawei.com/ca/support/content/en-us15827504/)) บอกว่า "ถ้าไม่มีเมนูนี้ แปลว่าอุปกรณ์ไม่รองรับ" ต้องให้ผู้ใช้เช็กที่นาฬิกา
- ถ้าไม่มีเมนูนี้ เว็บแอปจะรับ HR สดจากนาฬิกาเรือนนี้ไม่ได้ ทางเลือกที่เหลือคือให้ Huawei Health ซิงก์ไป Strava แล้วดึงข้อมูลหลังออกกำลังกาย ([PLAN-STRAVA-SYNC](PLAN-STRAVA-SYNC.md)) หรือใช้สายคาดอกวัดชีพจรแทน
