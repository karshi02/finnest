## คำขอ

> ทำให้เชื่อมต่อกับสมาร์ทวอทช์ได้จริง รุ่น Huawei เครื่อง Android

## Huawei ส่งค่าหัวใจให้แอปอื่นได้อย่างไร

นาฬิกาและสายรัด Huawei มีโหมด **HR Data Broadcasts** ที่ส่งค่าหัวใจผ่าน Bluetooth ให้อุปกรณ์หรือแอปอื่นเชื่อมต่อได้ ([Huawei Support](https://consumer.huawei.com/ca/support/content/en-us15827504/)):
- เปิดที่นาฬิกา: **รายการแอป > ตั้งค่า > HR Data Broadcasts** แล้วกดเปิด
- รุ่นที่เชื่อมได้ทีละเครื่อง จะตัดจากแอป Huawei Health ชั่วคราวระหว่างส่ง
- **Watch 5 / Watch Ultimate 2 / Ultimate Design** ส่งได้เฉพาะตอนเปิด **โหมดประหยัดแบตเตอรี่**

แอปนี้รับค่าผ่าน Web Bluetooth ตามมาตรฐาน Heart Rate Service อยู่แล้ว (ดู [FIX-REPORT-04](FIX-REPORT-04.md)) รอบนี้จึงปรับให้หา Huawei เจอง่ายขึ้น และแจ้งปัญหาให้ชัดขึ้น

## สิ่งที่แก้ (`index.html`, `sw.js`)

| เรื่อง | ก่อน | หลัง |
|---|---|---|
| การค้นหาอุปกรณ์ | แสดงเฉพาะอุปกรณ์ที่โฆษณา service `heart_rate` | ค้นจากชื่อ `HUAWEI` / `HONOR` ด้วย เผื่อบางรุ่นไม่ใส่ UUID ในสัญญาณโฆษณา |
| หาไม่เจอ | บอกแค่ว่า "ไม่ได้เลือกอุปกรณ์" | แนะนำให้เปิด HR Data Broadcasts และมีปุ่ม **"แสดงอุปกรณ์ทั้งหมด"** |
| เลือกเครื่องที่ไม่ได้ส่ง HR | error ภาษาอังกฤษ แล้วพยายามเชื่อมใหม่ซ้ำ | แจ้งว่า "ยังไม่ได้ส่งค่าหัวใจ ให้เปิดหน้า HR Data Broadcasts ค้างไว้" และไม่วนเชื่อมใหม่ |
| ไม่มีสิทธิ์ Bluetooth | error ดิบ | แนะนำให้เปิด Bluetooth และให้สิทธิ์ "อุปกรณ์ใกล้เคียง/ตำแหน่ง" กับ Chrome |
| คำแนะนำในแอป | ไม่มี Huawei | เพิ่มขั้นตอนสำหรับ Huawei และบอกว่าต้องใช้ Chrome (Huawei Browser ไม่รองรับ) |
| `sw.js` | cache `fittrack-v2` | `fittrack-v3` ให้มือถือที่เคยเปิดแอปได้โค้ดใหม่ |

**ยังไม่ได้ทดสอบกับนาฬิกา Huawei จริง** เพราะเครื่องนี้ไม่มีอุปกรณ์ Bluetooth ต้องลองตามขั้นตอนด้านล่าง

## วิธีใช้บนมือถือ Android

1. นาฬิกา: **รายการแอป > ตั้งค่า > HR Data Broadcasts** แล้วเปิดค้างไว้
2. มือถือ: เปิด Bluetooth และเปิด **Chrome** ไปที่ https://fitt-zeta.vercel.app
3. หน้า **คาร์ดิโอ > จับเวลา** แล้วกด **เชื่อมต่อ**
4. ถ้า Chrome ขอสิทธิ์ "อุปกรณ์ใกล้เคียง" หรือ "ตำแหน่ง" ให้กดอนุญาต
5. เลือก `HUAWEI WATCH ...` จากรายการ ถ้าไม่เห็น ให้กด **แสดงอุปกรณ์ทั้งหมด**
6. กดเริ่ม Stopwatch เมื่อจบให้กด "บันทึกเป็นคาร์ดิโอ"

ถ้ายังไม่เจอ:
- ตรวจว่าหน้า HR Data Broadcasts บนนาฬิกายังเปิดอยู่
- ปิดแอป Huawei Health ชั่วคราว
- มือถือ Huawei ที่ไม่มี Google: ต้องติดตั้ง Chrome ก่อน
- Watch 5 / Ultimate 2: เปิดโหมดประหยัดแบตเตอรี่ก่อน
