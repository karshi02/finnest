## คำขอ

> ขอคำสั่งให้ลูกค้าโหลดงานไปได้ และคำสั่งเดียวรันเบราว์เซอร์เองได้ด้วย

## สิ่งที่ทำ

| ไฟล์ | รายละเอียด |
|---|---|
| `run.ps1` (ใหม่) | ตัวเปิดแอปที่ใช้ได้กับ Windows ทุกเครื่อง **โดยไม่ต้องติดตั้ง Git หรือ Python** เพราะใช้ PowerShell 5.1 ที่ติดมากับ Windows: ดาวน์โหลด zip จาก GitHub → แตกไฟล์ไว้ที่ `%LOCALAPPDATA%\FitTrack` → เปิด web server (`HttpListener`) ที่ `http://localhost:8080` → เปิดเบราว์เซอร์ |
| `start.bat` | เปลี่ยนให้เรียก `run.ps1` จึงไม่ต้องมี Python อีกแล้ว |
| `README.md` | ใส่คำสั่งสำหรับลูกค้าแบบบรรทัดเดียว + วิธีสำหรับนักพัฒนา |

**คำสั่งสำหรับลูกค้า** (วางใน PowerShell):

```powershell
irm https://raw.githubusercontent.com/teslatesla040-del/fitt/main/run.ps1 | iex
```

### ตัดสินใจไว้แบบนี้ เพราะอะไร

- **พอร์ตตายตัว 8080:** ข้อมูลใน localStorage ผูกกับ origin (`http://localhost:8080`) ถ้าย้ายพอร์ตเองตอนพอร์ตไม่ว่าง ลูกค้าจะเห็นแอปว่างเหมือนข้อมูลหาย ถ้าพอร์ตไม่ว่างจึงแจ้งให้ปิดโปรแกรมที่ใช้อยู่แทน ถ้าตัวที่ใช้พอร์ตอยู่คือ FitTrack เองที่เปิดค้างไว้ จะเปิดเบราว์เซอร์ให้เลย
- **ดาวน์โหลดใหม่ทุกครั้ง:** ลูกค้าได้เวอร์ชันล่าสุดเสมอ ลบแล้วแตกใหม่ได้โดยข้อมูลไม่หาย เพราะข้อมูลอยู่ในเบราว์เซอร์ ไม่ได้อยู่ในโฟลเดอร์
- **ASCII ล้วน ไม่มี BOM:** ทดสอบแล้วว่าถ้าสคริปต์มี BOM `iex` บน PowerShell 5.1 จะขึ้น error `The term '﻿Write-Output' is not recognized` ข้อความในสคริปต์จึงเป็นภาษาอังกฤษ
- **กัน path traversal:** เปิดได้เฉพาะไฟล์ในโฟลเดอร์แอป
- **ส่ง header `Cache-Control: no-cache`:** ให้ service worker เห็นเวอร์ชันใหม่ทันที

## ⚠️ ยังใช้ไม่ได้จนกว่าจะ push สำเร็จ

push ไป GitHub ไม่ผ่าน (`403: Permission to teslatesla040-del/fitt.git denied to karshi02`) ผลคือ:
- บน GitHub ยังไม่มี `run.ps1` ตอนนี้ **คำสั่ง `irm ... | iex` ของลูกค้าจะได้ 404**
- ทดสอบโหมดดาวน์โหลดแล้วได้แอป**เวอร์ชันเก่า** จาก GitHub (ไม่มีวิดีโอ ไม่มี HR สด) เพราะสคริปต์ทำงานถูก แต่บน GitHub ยังเป็นเวอร์ชันเก่า

**วิธีแก้ (เลือกอย่างใดอย่างหนึ่ง):**
1. บัญชี teslatesla040-del → repo `fitt` → Settings → Collaborators → เพิ่ม `karshi02` แล้วกดรับคำเชิญ จากนั้นให้ผม push
2. ล็อกอิน git บนเครื่องนี้ด้วยบัญชี teslatesla040-del แล้ว `git push origin main`

## ข้อจำกัด

- `run.ps1` ใช้ได้กับ **Windows** เท่านั้น ลูกค้า Android หรือ iPhone ควรใช้ลิงก์เว็บ (GitHub Pages) แล้ว "ติดตั้งแอป" จาก Chrome ซึ่งเหมาะกว่าสำหรับลูกค้า
- ต้องเปิดหน้าต่าง PowerShell ทิ้งไว้ระหว่างใช้งาน
- บางองค์กรปิดการใช้ `irm | iex` ด้วย policy ความปลอดภัย ถ้าเจอกรณีนี้ ให้ดาวน์โหลด zip จาก GitHub แล้วดับเบิลคลิก `start.bat` แทน
